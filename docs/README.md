# Tool guides

This directory contains the user-facing guide for each tool in the repository.

| Tool | Purpose | Guide |
| --- | --- | --- |
| `x-likes` | Import and enrich liked posts from an exported X account archive | [Usage guide](tools/x-likes.md) |
| `catalog` | Build an offline cross-platform catalog from likes and bookmark sources | [Usage guide](tools/media-catalog.md) |

Each guide documents setup, inputs, commands, generated data, privacy considerations, and
recovery or troubleshooting steps. Add a guide here when adding another tool.
